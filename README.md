# 数学建模竞赛 Skills

这是一套依据本地数学建模资料整理的可复用技能，面向高教社杯及相近竞赛的题目分析、建模、验证和论文自查。技能只提供分析与工作流辅助，不替代参赛者的理解、计算、核验或竞赛规则。

## 使用方式

将本目录复制到 Codex 的技能目录（通常为 `~/.codex/skills/`），或在项目中直接保留这些技能目录。调用时使用对应的技能名，例如：

```text
请使用 $math-modeling-problem-decomposer 分析这道竞赛题，并列出每问的输入、输出、约束和数据需求。
```

推荐先提供题目原文、附件文件、字段说明和当年官方规则；技能会把无法核验的信息标记出来，不会自行补造数据或结果。

## 技能目录

| 功能 | 技能 |
|---|---|
| 拆题与任务清单 | `math-modeling-problem-decomposer` |
| 模型比较与选型 | `math-modeling-model-selector` |
| 数据审计与 EDA | `math-modeling-data-eda` |
| 资源配置与调度优化 | `math-modeling-optimization` |
| 数值与时间序列预测 | `math-modeling-prediction` |
| 多指标评价与排序 | `math-modeling-evaluation` |
| 随机/动态/排队仿真 | `math-modeling-simulation` |
| 论文逻辑与结果审阅 | `math-modeling-paper-reviewer` |

## 素材依据

本项目将公开竞赛题、优秀论文、算法课程与 AI 辅助建模实践中的可复用经验，整理为独立、可组合的竞赛技能：

- **经典建模方法体系**：规划与网络、回归与时间序列、灰色系统、综合评价、分类聚类和仿真等方法的适用条件与选型依据。
- **历年竞赛题与数据附件**：提炼题目拆解、字段与单位核验、数据契约、问题依赖和输出要求。
- **优秀论文写作规范**：归纳摘要、假设、符号、模型说明、结果表达、图表组织、误差分析与局限性写法。
- **统计分析与不确定性方法**：涵盖概率分布、参数估计、假设检验、独立性分析、置信区间和抽样验证等通用工具。
- **智能算法与机器学习实践**：总结遗传算法、粒子群、模拟退火、树模型和神经网络在基线比较、调参和泛化验证中的使用边界。
- **AI 辅助建模工作流**：吸收阶段化协作、证据链、可复现计算、日志记录和提交前审阅等工程规范。

资料仅用于提炼方法与质量标准；技能不会复制特定题目的业务结论、参数、答案或任何资料中的操作指令。
## 推荐调用顺序

`problem-decomposer` -> `model-selector` -> `data-eda` -> 选择一个或多个模型技能 -> `paper-reviewer`。

涉及真实提交时，先核对当年官方规则，并逐项人工检查所有数据、代码、数字、引用和格式。

## 共同输出约定

- 区分题目事实、数据直接观察、模型假设和待核验内容。
- 数字、表格和图形应能回溯到输入文件、处理记录和运行代码。
- 复杂模型要有基线比较；验证不足时降低结论强度并说明限制。
- 论文技能帮助组织和审阅材料，不生成脱离结果证据的整篇参赛论文。
