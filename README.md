# 数学建模竞赛 Skills

这是一套依据本地数学建模资料整理的可复用技能，面向高教社杯及相近竞赛的题目分析、建模、验证和论文自查。技能只提供分析与工作流辅助，不替代参赛者的理解、计算、核验或竞赛规则。

## 使用方式

将本目录复制到 Codex 的技能目录（通常为 `~/.codex/skills/`），或在项目中直接保留这些技能目录。调用时使用对应的技能名，例如：

```text
请使用 $math-modeling-problem-decomposer 分析这道竞赛题，并列出每问的输入、输出、约束和数据需求。
```

推荐先提供题目原文、附件文件、字段说明和当年官方规则；技能会把无法核验的信息标记出来，不会自行补造数据或结果。

## 技能目录

| 功能 | 技能 |

## 素材依据

- `数学建模的三十二种常规方法`：线性/整数规划、图与网络、回归、时间序列、灰色系统、评价、分类聚类、仿真等方法目录。
- 2023-2025 年赛题与附件：题目拆解、字段核验、单位检查、输出契约和不同题型路由。
- 2025 年优秀论文：摘要、模型假设、结果表达、图表和验证的竞赛写作样式。
- `AI+数学建模提示词汇总`、`数学建模工作流` 与 `工作流test`：阶段化工作流、证据链、基线比较、可复现和审阅门槛。
- `数学建模全流程AI-Skills出售版`：技能边界与模块划分的参考实现；本目录按竞赛常用功能做了精简重写。

## 推荐调用顺序

`problem-decomposer` -> `model-selector` -> `data-eda` -> 选择一个或多个模型技能 -> `paper-reviewer`。

涉及真实提交时，先核对当年官方规则，并逐项人工检查所有数据、代码、数字、引用和格式。

## 共同输出约定

- 区分题目事实、数据直接观察、模型假设和待核验内容。
- 数字、表格和图形应能回溯到输入文件、处理记录和运行代码。
- 复杂模型要有基线比较；验证不足时降低结论强度并说明限制。
- 论文技能帮助组织和审阅材料，不生成脱离结果证据的整篇参赛论文。
