# 通用方法路由

根据问题结构选择方法，并先做低复杂度基线：

- 趋势预测：样本少且信息有限时可试灰色模型；有连续观测和自相关时比较 ARIMA/状态空间；均需留后验证、残差诊断和外推边界说明。
- 非线性关系：由散点图、残差系统偏差或机制判断触发；从低阶多项式/可解释曲线开始，用 AIC/BIC 与交叉验证控制过拟合。
- 统计推断：先核对独立性、分布和抽样单位，再选择参数或非参数检验，报告效应量、区间和多重比较处理。
- 随机估计：Monte Carlo 要预设样本量、收敛/误差标准、种子和置信区间；必要时采用方差缩减。
- 状态转移：马尔可夫模型须检查转移矩阵样本支持、齐次性和稳态假设。
- 复杂优化/机器学习：遗传、粒子群、模拟退火、树模型或神经网络须证明相对基线的验证收益，并报告调参和泛化风险。
- 机理模型：明确参数来源、初始/边界条件和可识别性，进行情景与敏感性分析。

资料中的案例只用于说明方法，不得把示例数据或结论迁移到新题目。
