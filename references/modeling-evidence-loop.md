# 通用建模证据链与复现规范

适用于所有题型的建模项目：

1. **输入契约**：为每个附件记录文件、工作表、字段、单位、时间范围、缺失编码和版本；原始附件只读，处理结果另存。
2. **统一数据层**：将异构表格转换为带字段字典的统一结构，保留原始记录与映射规则；对合并单元格、区间价格、分类名称和季次等编码显式归一化。
3. **阶段化计算**：按“预处理→基线→主模型→验证→制图/写作”组织脚本；每阶段固定入口、输出目录和日志，失败即停止并保留日志。
4. **结果可追溯**：每个关键数字、图和表都记录输入版本、参数、随机种子（如有）和生成脚本；结论只能引用已生成且可定位的结果。
5. **验证矩阵**：按任务选择误差、可行性、守恒/边界、滚动或留后、交叉验证、情景扰动、参数敏感性、消融和不确定性区间；不要用单一指标代替验证。
6. **模型阶梯**：先跑可解释基线，再加入复杂机制；只有在验证指标或业务解释明显改善时保留复杂模型。
7. **交付检查**：运行一键复算或最小复现脚本，检查输出文件存在、数值无 NaN/无单位错位、图表与正文一致，并记录环境与依赖版本。

将案例中的具体作物、年份、参数和结论视为示例，不能直接迁移到其他题目。
