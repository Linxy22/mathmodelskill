# 数学建模竞赛：仿真建模

## 工作方式

1. 定义状态、事件、转移机制、初始条件、边界条件、时间步长和停止规则。
2. 从题目或数据估计分布和参数；无法确认的分布要列为假设并做替代分布分析。
3. 固定随机种子，预先设定重复次数、预热期、采样频率和输出指标；区分单次轨迹与总体统计量。
4. 用基线场景、极端场景和参数扰动验证模型；报告均值、方差、分位数或置信区间。
5. 检查守恒关系、边界行为、重复运行稳定性和与已知解析结果的对照。

## 输出

给出机制图或状态表、参数来源、仿真代码、场景表、统计结果和局限性。不要把一次随机运行的结果写成确定性结论。

## 通用验证要求

把模型运行组织为可复算阶段，保存参数、版本、随机种子和日志；至少提供基线对照、适配任务的验证指标及一项敏感性或情景分析。结果必须能沿证据链回溯，详见 [通用证据链](../references/modeling-evidence-loop.md)。
