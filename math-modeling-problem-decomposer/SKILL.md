# 数学建模竞赛：题目拆解

## 目标

把题目原文转成可执行的建模任务清单，并区分题目明示信息、由附件核验的信息和仍待确认的假设。

## 工作方式

1. 识别竞赛、年份、题号、提交规则、语言和格式要求；缺失时标记“待确认”。
2. 对每一问分别列出：原始要求、直接目标、隐含目标、输入数据、输出字段、决策变量/状态变量、参数、约束、评价指标、与其他问题的依赖。
3. 判断问题本质：预测、评价、统计推断、分类聚类、优化、网络、微分方程、仿真或混合问题，并给出判断依据。
4. 检查附件字段、单位、时间范围、样本量、缺失值和重复记录；不能读取的内容标记“未核验”，不要猜测。
5. 为每问提出一个可解释的基线方案，以及升级方案的触发条件。

## 输出格式

先给出“题目总览”和“信息缺口”，再用表格列出各小问，最后给出问题依赖图和建议的下一步。不要生成尚未计算的数值结论。

## 竞赛约束

- 题号 A-F 只作为经验标签，不能替代对任务机制的判断。
- 每个输出必须能回溯到题目要求或附件字段。
- 对不确定的单位、边界条件、评分口径和外部资料明确标注风险。
